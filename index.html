Admin guide

管理员使用说明

管理员模式的所有修改都会自动保存到当前浏览器的 IndexedDB 数据库；这里没有服务器，也不会同步到其它设备。

1 · 修改文案与长文

点击照片下方的短标题或悬停小字，直接输入；打开大图后可编辑标题与注释。长文点右侧「编辑长文」，在富文本编辑器里加粗、斜体、分段、引用或列表。点击空白处或按 Esc 保存到本机数据库。

2 · 调整分组与照片

拖动照片右上角的 ⠿ 手柄到其他分组；× 移除照片。点「＋ 添加新照片」可从本机上传（自动压缩为 WebP），或从内置示例图片中勾选后一次导入同一分组。

「分组管理」可新增、重命名、排序或删除章节，Chapter 01、02… 与照片编号会自动同步。

每张照片左下角有「分组」下拉框（即之前看到的 1/2 等选项）：显示当前分组，切换后照片立刻移到该分组，其它照片会自动让位、页面重新排布。

按住 ⠿ 左键拖动照片；拖动过程中用鼠标滚轮上下滚动页面（不再自动滚动，避免页面抽动）。经过其它章节的分界线并进入其照片区域时，该章节会高亮，松手即完成换组。

3 · 自由排版与旋转缩放

点「自由排版」开启：拖动任意照片右上角 ⠿ 可自由移动位置，拖动照片右下角圆点可调整宽度；所有照片按分组画布自由叠放，访客看到的也是这个排版。

点击任意照片后，屏幕底部会出现滑杆：旋转 −180°～180°、缩放 40%～200%，可即时预览并保存；「重置旋转缩放」恢复 0° / 100%。旋转缩放只作用于作品卡片，不会影响打开大图后的显示。

「排版总览」把所有章节按真实比例缩小成一张总览板：拖缩略图调位置、拖右下角方块调宽度、点击后用同样的滑杆旋转缩放，适合在不放大的情况下整体调整；把缩略图拖到其它章节的画布上即可直接换组，空章节也可以放入。

「清除排版」会恢复默认的杂志式排列（只删位置与旋转缩放，不删照片和文字）；「退出自由排版」只是停止编辑，排版结果仍会保留。

4 · 备份与恢复

管理员面板顶部的【📦 导出备份】会把完整数据（含照片）打包为 JSON 下载；【📥 导入备份】会用所选文件覆盖当前设备上的全部数据，导入前请先导出旧备份。

清理浏览器缓存、使用无痕窗口或更换设备都会导致数据丢失，请定期导出并把 JSON 保存到其它位置。

5 · 撤销与重做

结构调整（导入、删除、拖拽换组）和文字编辑都支持 Ctrl + Z 撤销、Ctrl + Shift + Z 或 Ctrl + Y 重做；在输入框内仍使用系统原生撤销。

配色方案只影响作品集外观；所有修改都保存在当前浏览器，请记得定期导出备份。
